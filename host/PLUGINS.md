# 应用开发与分享

Host 的「应用」统一管理远程 MCP 服务、带代码的应用和附带技能。旧版插件 JSON 仍可导入；新包使用 `grokbot-app`。

- 内置「编写应用」提供开发指南、格式校验和提交工具。Bot 提交后，用户在 Mac/iOS 原「连接应用」目录添加并授权。
- 导入、导出使用单个 JSON，包含代码、图标、说明和技能；保存的配置与授权凭证不进入导出包。
- 代码应用通过现有 Linux 执行电脑的 MCP 进程运行，不再部署插件执行器或每应用 Docker 容器。应用与该电脑上的其他任务共享用户权限、文件和网络。
- OAuth 支持 PKCE、一次性 state、过期刷新。应用开发者声明授权地址、Token 地址与 scopes；用户配置 Client ID/Secret，再从客户端打开服务商授权页面。
- 复杂编码调用已连接 Mac 的 Codex，沿用 Mac 上的模型设置和登录。

完整包格式、可运行示例和 OAuth 代码示例见 [应用开发指南](server/application-guide.md)。

已有配置、应用 ID、原客户端目录协议保持兼容。版本内容不可覆盖，升级后可恢复前一版本。
